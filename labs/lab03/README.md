## 1. Опис предметної області та сутностей

Вебзастосунок реалізує REST API для реєстрації, збереження, фільтрації та аналізу вимірювань тривалості відновлення критичних сервісів після збоїв чи інцидентів кібербезпеки.

### Сутності бази даних:
1. **Категорії сервісів (`categories`)**:
   - `id` (`INTEGER PRIMARY KEY`): унікальний числовий ідентифікатор ($id > 0$).
   - `name` (`TEXT NOT NULL UNIQUE`): унікальна назва категорії (довжина 2–40 символів).
   - Базові категорії варіанта 8:
     - `1`: `database` — сервіси баз даних;
     - `2`: `web_service` — зовнішні та внутрішні вебсервіси;
     - `3`: `file_storage` — файлові сховища та сховища резервних копій.

2. **Записи вимірювань (`records`)**:
   - `id` (`INTEGER PRIMARY KEY`): унікальний числовий ідентифікатор запису ($id > 0$).
   - `code` (`TEXT NOT NULL UNIQUE`): унікальний літерно-цифровий код вимірювання (3–40 символів, наприклад `V08-01`).
   - `title` (`TEXT NOT NULL`): описова назва вимірювання (3–120 символів, наприклад `Вимірювання відновлення 01`).
   - `category_id` (`INTEGER NOT NULL`): зовнішній ключ, що посилається на `categories(id)` (`ON DELETE RESTRICT`).
   - `value` (`REAL NOT NULL`): виміряний час відновлення сервісу у хвилинах ($value \ge 0.0$, скінченне число).
   - `status` (`TEXT NOT NULL`): поточний статус опрацювання запису (`new`, `in_progress`, `done`).

## 3. Встановлення залежностей та налаштування середовища

Усі команди виконуються з **кореня репозиторію** `cybersecurity-python-labs/` в активованому віртуальному середовищі (Python 3.10 або новішому):

```bash
# Активація віртуального середовища (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Встановлення необхідних залежностей
pip install -r requirements.txt
```

Основні бібліотеки:
- `fastapi` — сучасний вебфреймворк для розробки REST API;
- `uvicorn` — асинхронний ASGI-сервер для запуску FastAPI;
- `pydantic` (v2) — валідація схем даних і типізація;
- `ruff` — швидкий лінтер та інструмент форматування Python-коду.

## 4. Створення та початкове заповнення бази даних

1. **Ініціалізація схеми бази даних (Крок 4.1.1)**:
   ```bash
   python -m labs.lab03.database
   ```
   Створює файл `labs/lab03/data/lab3.sqlite3` із таблицями `categories` та `records` за файлом `schema.sql`.

2. **Початкове заповнення даними Варіанта 8 (Крок 4.1.2)**:
   ```bash
   python -m labs.lab03.seed
   ```
   - Завантажує дані з `labs/lab03/data/seed.json` (3 категорії та 8 записів).
   - Здійснює попередню сувору валідацію типів, меж та унікальності полів.
   - Заповнює порожню базу в межах **єдиної атомарної транзакції**.
   - При повторному запуску повідомляє, що база вже заповнена, запобігаючи дублюванню даних:
     ```text
     База даних вже містить записи. Початкове заповнення пропущено.
     ```

### 6.4. Пакетне додавання та перевірка транзакцій (/records/bulk)

#### Успішний пакет із двох записів:
```bash
curl -i -X POST http://127.0.0.1:8000/records/bulk \
  -H "Content-Type: application/json" \
  -d '[
    {
      "code": "V08-10",
      "title": "Пакетне вимірювання 1",
      "category_id": 1,
      "value": 30.0,
      "status": "new"
    },
    {
      "code": "V08-11",
      "title": "Пакетне вимірювання 2",
      "category_id": 2,
      "value": 25.0,
      "status": "in_progress"
    }
  ]'
```
**Очікувана відповідь (201 Created):** список з обох створених об'єктів.

#### Перевірка атомарного відкочування транзакції (Rollback):
Якщо перший елемент новий, а другий містить дублікат коду (`V08-01` вже є в базі):
```bash
curl -i -X POST http://127.0.0.1:8000/records/bulk \
  -H "Content-Type: application/json" \
  -d '[
    {
      "code": "V08-ROLLBACK",
      "title": "Цей запис не повинен зберегтися",
      "category_id": 1,
      "value": 15.0,
      "status": "new"
    },
    {
      "code": "V08-01",
      "title": "Дублікат коду",
      "category_id": 2,
      "value": 20.0,
      "status": "new"
    }
  ]'
```
**Очікувана відповідь (409 Conflict):**
```json
{
  "detail": "Запис із кодом 'V08-01' вже існує в базі."
}
```
*Запис `V08-ROLLBACK` гарантовано не потрапляє до бази, збереження даних є атомарним.*
