Лабораторна робота №2: Розробка консольних утиліт для задач кібербезпеки

Варіант: 8
Тема: Фільтр та аналізатор журналів DNS-запитів

1. Встановлення залежностей:
pip install -r requirements.txt

2. Структура файлів даних:
- labs/lab02/data/data_v08/blacklist.txt - локальний чорний список підозрілих та шкідливих доменних імен
- labs/lab02/data/data_v08/dns_queries.csv - журнал DNS-транзакцій з полями: Timestamp, ClientIP, Domain, QueryType
- labs/lab02/data/dns_alerts.csv - результуючий звіт про виявлені загрози та аномалії

3. Параметри командного рядка (CLI):
--dns-log: шлях до вхідного журналу DNS-запитів у форматі CSV 
--blacklist: шлях до текстового файлу локального чорного списку доменів 
--out-csv: шлях для збереження результуючого звіту виявлених загроз у 
--min-domain-len: числовий поріг довжини домену для виявлення ознак DGA або тунелювання

4. Поведінка програми при помилках:
- FileNotFoundError: перехоплюється при відсутності журналу DNS або файлу чорного списку, виводить повідомлення про відсутній файл у потік помилок stderr та завершує роботу з кодом помилки.
- PermissionError: обробляє ситуації відсутності прав доступу на читання вхідних даних або створення вихідного CSV-звіту.
- OSError: перехоплює загальні помилки роботи операційної системи з файловою системою.
- Порожні рядки та некоректні записи всередині файлу логу ігноруються без аварійного переривання аналізу.

5. Контроль якості коду (Ruff):
ruff check labs/lab02/
ruff format --check labs/lab02/

6. Команди запуску:
- python -m labs.lab02.main demo
- python -m labs.lab02.main analyze --dns-log labs/lab02/data/data_v08/dns_queries.csv --blacklist labs/lab02/data/data_v08/blacklist.txt --out-csv labs/lab02/data/dns_alerts.csv

7. Опис параметрів командного рядка (CLI):

Головний скрипт (labs.lab02.main) підтримує дві підкоманди:

- demo — запуск демонстраційного режиму для Завдання 1 (робота з ООП-моделями користувачів, сесіями та правами доступу).
- analyze — запуск утиліти аналізу журналів DNS-запитів для Завдання 2 (Варіант 8).

Аргументи для підкоманди analyze:

- --dns-log (обов'язковий)
  Шлях до вхідного журналу DNS-запитів у формате CSV.

- --blacklist (обов'язковий)
  Шлях до текстового файлу локального чорного списку доменних імен.

- --out-csv (обов'язковий)
  Шлях до підсумкового CSV-файлу, куди експортуються виявлені аномалії та загрози.

- --min-domain-len (необов'язковий, значення за замовчуванням: 30)
  Поріг довжини доменного імені (у символах) для виявлення потенційних DGA-доменів та DNS-тунелювання.
